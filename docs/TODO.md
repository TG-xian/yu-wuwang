   - 登录入口：网易云与 B 站两个登录入口合并成**一个按钮**，或放在一起的两个靠近的按钮
   - 搜索：做成**融合搜索** —— 输入一个关键词，同时搜两个源（网易云 + B 站）
   - B 站页要重做：左侧分成「B 站推荐」「B 站榜单」等多个子页面
   - 现状问题：把 B 站单拎成侧栏一个入口，**整体性不好**（原文）

4. **播放页：点歌词跳转**
   - 点击某一句歌词，直接 seek 到那句的位置
   - 是**全局功能**，不限于 B 站源（网易云、本地都适用）

5. **B 站源的「专辑 / 歌手 / 合集」点击**
   - 点歌手（= UP 主）→ 跳该 UP 主所有歌的页面
   - 点合集 → 跳这首歌所在合集的页面
