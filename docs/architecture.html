YU · WUWANG / SYSTEM ARCHITECTURE

豫 · 无妄

从在线音源到 ASIO 独占输出：三进程协作、两条播放链路、源采样率直通。

01 / PROCESS MODEL

三进程模型

Main 管理窗口、IPC、托盘及缓存，并拉起 engine/ 与 NeteaseCloudMusicApi 两个子进程。Renderer 承载 UI，通过 IPC 与主进程协作，通过 WS 47800 连接引擎。

02 / SOURCE ROUTING

两条音源链路

网易云经本地 3000 端口取流服务获取直链，直接流式播放，不落盘。B 站由 Main 直连获取 DASH，下载到 userData/bili-cache 后播放文件，避开 fMP4 的 err=41。

03 / EXCLUSIVE OUTPUT

直通不重采样

两种入口汇入 BASS 解码，经 ASIO 独占输出到声卡。按音源匹配采样率，44.1k / 48k / 96k / 192k 直通，不重采样。
