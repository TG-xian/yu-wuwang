## 文件 1：`docs/logo-anatomy.html` —— Logo 设计理念与拆解

画布建议 `viewBox="0 0 1440 800"`。

### 要讲清的核心（这是真实实现，别改数字）

Logo 叫「九爻印」，由**两个六爻卦叠合**而成：

- **豫卦**：上卦 震 ☳、下卦 坤 ☷ → 六爻（上→下）：`0,0,1,0,0,0`
- **无妄卦**：上卦 乾 ☰、下卦 震 ☳ → 六爻（上→下）：`1,1,1,0,0,1`
- 两卦**共用中间那个「震」**，6 + 6 − 3 = **九爻**：
  上三层 **乾 ☰（3 阳爻）** / 中间 **震 ☳（阴阴 阳）** / 下三层 **坤 ☷（3 阴爻）**
- 即代码里的 `SEQ = [1,1,1,0,0,1,0,0,0]`（1=阳爻实线，0=阴爻断线，**从上往下**排列）

### 拆解区（左侧）

1. 豫卦 ☷☳ 六爻小图（标注「震上坤下」）
2. 无妄卦 ☳☰ 六爻小图（标注「乾上震下」）
3. 中间用一个大括号/箭头汇聚 → 九爻印大图
4. 九爻印上用**引线**标出三层：乾（上）/ 震（中，高亮描边表示「共用层」）/ 坤（下）

### 右侧：几何与配色规格表

| 爻宽 | 56 |

### 三档密度（也要画出来，这是真实的响应式设计）

- **std**（≥32px）：完整九爻 + 外框 + 三层金
- **opt**（≤24px）：去外框、线宽加到 5.8、断口放宽到 17、单层亮金 `#F5D882`（小尺寸下保证辨识）
- **plain**：无外框，仅爻线，用作播放页水印/底纹

三个尺寸画成 96px / 24px / 96px 三档并排，让人肉眼看出「为什么小尺寸要改参数」。

### 设计理念文案（用一两句话点出来，别太长）

「豫」与「无妄」共用一爻，叠成九爻——多出来的三爻不是装饰，是两卦重合的部分。

## 文件 2：`docs/player-anatomy.html` —— 播放页元素拆解与动画讲解

画布建议 `viewBox="0 0 1440 900"`。

### 左侧：爆炸图（由下往上分层，各层之间留间隙 + 引线标注）

真实 DOM 层级（自上而下是 z 轴顺序，画的时候按「底 → 顶」从下往上排）：

1. **deck 底盘** — 最外容器
2. **plinth 底台** — 承载唱片；上面有 `<div class="emboss">` **压印 logo**（九爻印，暗金、低透明度）
3. **disc 唱片** — 圆形，`::before` 是 `conic-gradient` 做的两道反光（26° 与 208° 处的白色高光，模拟黑胶光泽），`::after` 是 `inset:12%` 的内圈细线
4. **label 封面** — 居中 150×150 圆，overflow hidden；`::after` 是**中心孔 9×9 圆**
5. **spin-ring 旋转环** — `inset:-5px` 的圆环边，播放时旋转
6. **arm 唱臂** — 位置 `right:-16px; top:-26px`，尺寸 **10×320px**，由 4 个零件组成：
   - `weight` 配重 / `pivot` 转轴 / `rod` 臂杆 / `head` 唱头

### 右侧：动画讲解（三块，各配一条示意曲线或关键帧条）

要讲的是三个真实动画，参数照抄：

**A. 落针 / 抬臂**
- `.arm.off` = `rotate(4deg) translateY(-5px)`（抬起状态）
- 播放时移除 `off` → 回到 0°（落针）
- 画一个 4° 的角度示意

**B. 换碟（最关键，要画曲线）**
- `disc-out`：旧碟 `translateY(0) scale(1) opacity 1` → `translateY(158px) scale(.8) opacity 0`（向下抽走）
- `disc-in`：`translateY(158px) scale(.8) opacity 0` → **72% 处 `translateY(-9px) scale(1.012)`（落盘过冲）** → `translateY(0) scale(1)`
- 用一条**竖直位移曲线**画出这个「过冲再回落」，把 72% 那个 -9px 的点标出来

**C. spin-ring 旋转**：`rotate(0→360deg)` 线性循环

### 底部摘要卡片（三张）

1. **为什么是黑胶**：播放页不做成波形/封面大图，而是唱盘——因为「不重采样」的理念需要一个物理隐喻：针落下去，出来什么就是什么。
2. **过冲的意义**：`disc-in` 在 72% 处过冲 -9px 再落定，模拟实体唱片落盘的惯性；纯线性动画会显得「贴纸」。
3. **小尺寸的妥协**：logo 在 ≤24px 时会去掉外框、加粗爻线、放宽断口——否则九条爻在小图标里会糊成一片。
