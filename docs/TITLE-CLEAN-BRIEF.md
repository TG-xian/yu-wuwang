# B 站标题清洗 + 播放页标题限行

## 背景

B 站歌名长这样：

```
【无损音质】《起风了》-买辣椒也用券  "起风了，也让我想起了那年夏天"
【SMTR25】SMTR25 Introduction film 松河
在百万豪装录音棚大声听买辣椒也用券《起风了》【Hi-res】
```

直接显示有两个问题：列表里读不出歌名；播放页标题撑得太高，把歌词区挤到屏幕外（用户实测，歌词需要滚动才看得到）。

## 要做三件事

### 1. 清洗函数（新增 `app/renderer/js/title-clean.js`）

```js
window.YW = window.YW || {};
window.YW.title = { clean(raw) };
```

规则（思路参考同类播放器，具体实现自己写）：

- **括号内的内容**（`【】[]（）()「」〈〉<>`）按分隔符 `／ / · ・ | ｜ ， 、 ； ： :` 切段，逐段判断：
  - 命中**视频元信息词** → 删掉该段：`中字 字幕 pv 官方mv mv 本家 熟肉 生肉 自译 自翻 自制 转载 搬运 翻唱 cover 4k 1080p 720p 60fps 高清 无水印 完整版 现场 直播 剪辑 混剪 合集 歌单 循环`
  - 命中**音质词** → 也删掉（用户要干净）：`无损 hi-res hires 杜比 dolby atmos 全景声 母带 flac 320k dsd 空间音频 高音质`
  - 其余**保留**（比如 `【乐正绫原创】` 里的“原创”、歌手名）
  - 括号被清空 → 整个括号删掉
- **括号外的正文不动**（避免误伤如「Video Games」这种歌名）
- 分隔符**不含 `-` 和 `.`**（`Hi-Res`、艺人名里有点号）
- 去掉头尾多余的分隔符和空白
- **兜底**：清洗后长度 < 2 或与原文相同 → 返回原文

⚠️ 别把它做成"删得越干净越好"。宁可留一点噪音，也不能把真歌名削掉。判不准就保守。

### 2. 显示替换

- `app/renderer/js/bili.js` 的 `toTrack(v, page)`（第 39 行附近）：构造 track 时
  - `t` = 清洗后的标题（列表、播放页都用它）
  - `bili.title` **保持原始标题**（歌词匹配要用原文，那里依赖它，别改）
  - 新增 `tRaw` = 原始标题（用于 hover）
- 列表行（`rowHtml`）与播放页：显示 `track.t`（清洗后），并给行/标题元素加 `title="<原始>"` 属性，鼠标悬停能看到原文
- **播放页 `#pl-title`**（`app.js:987` 附近）：显示清洗后标题，并在 CSS 里**限行 2 行**（超出省略），避免再把歌词挤出视口

### 3. 验收探针

`tools/bili-probe.js` 增加 `--clean "<标题>"`，打印清洗前后对比。

## 硬约束

- 不改 `engine/`、不改网易云逻辑、不改歌词匹配用的原始标题
- 不引入新依赖
- 不复制开源项目代码（规则表可以照通用常识自己写）
- 播放页限行用 CSS 变量与现有风格，不新配色

## 验收（我会自己跑）

1. `node tools/bili-probe.js --clean "【无损音质】《起风了》-买辣椒也用券  “起风了，也让我想起了那年夏天”"` → 期望接近「《起风了》-买辣椒也用券」
2. `--clean "【SMTR25】SMTR25 Introduction film 松河"` → 期望保留 `SMTR25 Introduction film 松河`
3. `--clean "在百万豪装录音棚大声听买辣椒也用券《起风了》【Hi-res】"` → 期望去掉 `【Hi-res】`
4. `--clean "Video Games"` → **必须原样返回**（不能被误删）
5. 启动应用，列表与播放页标题变短，播放页标题最多两行，歌词区回到视口内
